Karakteristik String & Mekanisme File Python

Sebelum mempelajari source code kegiatan praktikum, pahami pilar-pilar penting bagaimana Python memperlakukan string, stream file teks, tabel CSV, dan hierarki JSON.

Sifat Immutability String

String bersifat immutable (tidak dapat diubah di tempat). Sintaks seperti s[0] = 'X' akan memicu TypeError. Setiap fungsi string (seperti .strip(), .replace(), .split()) menghasilkan objek string baru di memori komputer.

File Context Manager (`with`)

Menggunakan with open(...) as f: menjamin file pointer ditutup secara otomatis saat keluar dari blok indentasi, bahkan saat terjadi *runtime exception*. Ini mencegah terjadinya memory leak atau *file lock* oleh sistem operasi.

Perbandingan Tiga Format Berkas Utama dalam Modul

Format Karakteristik Utama Modul Python Standar Struktur Data Python
Teks (.txt) Aliran karakter linier, dipisahkan karakter pindah baris (\n). Bawaan (open) str / list of str
CSV (.csv) Representasi baris-kolom terpisah delimiter (, atau ;). import csv list of dict (DictReader)
JSON (.json) Format terstruktur berbasis hierarki key-value JavaScript Object Notation. import json dict / list of dict

10.4.1 Mengubah Isi File JSON (`nasabah.json`)

Tugas: Membaca berkas nasabah.json, mengubah nama nasabah pertama menjadi Agus Gus Gus Gus, mengubah saldo nasabah kedua menjadi 300000, lalu menyimpannya kembali.

ubah_json.py (Lengkap) 
1import json
2
3# Inisialisasi variabel penampung data objek
4data = None
5
6# 1. Buka file nasabah.json dalam mode read ('r') & deserialisasi ke list of dict
7with open('nasabah.json', 'r') as datafile:
8    data = json.load(datafile)
9
10# 2. Modifikasi nilai field spesifik menggunakan indeks list & key dictionary
11data[0]['nama'] = 'Agus Gus Gus Gus'
12data[1]['saldo'] = 300000
13
14# 3. Buka file kembali dalam mode write ('w') & simpan kembali objek ke format JSON
15with open('nasabah.json', 'w') as datafile:
16    json.dump(data, datafile, indent=2)
17
18print("Proses modifikasi file nasabah.json berhasil dilakukan!")

Penjelasan Baris demi Baris / Blok Kode (Detailed Breakdown)

Baris 1 & 4 import json dan data = None

Fungsi: Mengimpor pustaka standar bawaan Python untuk pengolahan format JSON. Variabel data diinisialisasi dengan nilai None agar variabel tersebut memiliki cakupan (*scope*) di luar blok with.

Baris 6 - 8 with open('nasabah.json', 'r') as datafile: data = json.load(datafile)

Fungsi: Membuka file dengan mode Read-Only ('r'). Fungsi json.load(datafile) melakukan proses Deserialisasi, yaitu membaca string teks JSON dari disk dan mengonversinya menjadi objek struktur data asli Python (dalam hal ini sebuah list yang menampung dua buah dict).

Baris 10 - 12 data[0]['nama'] = 'Agus Gus Gus Gus' & data[1]['saldo'] = 300000

Fungsi: Melakukan modifikasi nilai di memori RAM.
• data[0] mengakses dictionary urutan pertama milik Agus Bagus, lalu key ['nama'] ditimpa dengan string baru.
• data[1] mengakses dictionary urutan kedua milik Bambang Gentolet, lalu key ['saldo'] diubah nilainya menjadi integer numerik 300000.

Baris 14 - 16 json.dump(data, datafile, indent=2)

Fungsi: File dibuka kembali dalam mode tulis 'w' (yang akan menimpa/overwrite isi lama). Fungsi json.dump() melakukan proses Serialisasi, yaitu mengubah list/dict Python menjadi string berformat JSON dan menyimpannya secara fisik ke media penyimpanan. Argumen indent=2 membuat file hasil keluaran rapi bertingkat (tidak menyatu dalam satu baris panjang).

10.4.2 Menambah Data File CSV (`menu.csv` → `menu-new.csv`)

Tugas: Membaca berkas menu.csv, membersihkan karakter whitespace tak kasat mata, menambahkan 4 menu baru menggunakan metode list append(), lalu menyimpannya ke berkas baru bernama menu-new.csv.

tambah_csv.py (Lengkap) 
1# 1. Buka dan baca seluruh baris file menu.csv
2data = None
3with open('menu.csv', 'r') as datafile:
4    data = datafile.readlines()
5
6# Bersihkan whitespace dan karakter newline '\n' di ujung tiap baris
7for i in range(0, len(data)):
8    data[i] = data[i].strip()
9
10# 2. Tambahkan data menu baru ke dalam list
11data.append('Makanan, Ayam Geprek Lombok Ijo, 20000')
12data.append('Makanan, Bebek Goreng, 25000')
13data.append('Makanan, Sate Kambing, 25000')
14data.append('Minuman, Es Doger, 15000')
15
16# 3. Simpan seluruh data gabungan ke file baru menu-new.csv
17with open('menu-new.csv', 'w') as datafile:
18    for line in data:
19        datafile.write(line + '\n')
20
21print("Sukses menulis menu-new.csv. Total baris:", len(data))

Penjelasan Baris demi Baris / Blok Kode (Detailed Breakdown)

Baris 3 - 4 with open('menu.csv', 'r') as datafile: data = datafile.readlines()

Fungsi: Metode .readlines() membaca seluruh teks dari berkas sekaligus dan memecahnya menjadi sebuah list string berdasarkan karakter pindah baris. Setiap elemen di dalam data merepresentasikan satu baris berkas CSV.

Baris 7 - 8 for i in range(0, len(data)): data[i] = data[i].strip()

Mengapa baris ini sangat krusial? Saat readlines() membaca file, karakter \n di ujung baris tetap ikut terbawa (misal: 'Makanan, Ayam Goreng, 15000\n'). Jika kita tidak memanggil .strip(), lalu saat menyimpan kembali kita menambahkan line + '\n', maka pada file baru akan tercipta dua kali baris baru (menghasilkan baris kosong ganda / spasi berlebih yang merusak format CSV).

Baris 11 - 14 data.append('Makanan, Ayam Geprek Lombok Ijo, 20000')

Fungsi: Menambahkan elemen string baru di indeks paling belakang dari list data. Format kolom harus konsisten dengan header baris pertama (Kategori, Nama, Harga).

Baris 17 - 19 with open('menu-new.csv', 'w') as datafile: datafile.write(line + '\n')

Fungsi: Berkas baru menu-new.csv dibuat dalam mode tulis ('w'). Karena tadi semua elemen sudah di-strip(), kita dengan aman menyambungkan karakter \n secara eksplisit agar setiap menu menempati baris baru yang rapi.

29def load_csv(file_like):

31        text = io.StringIO(file_like.getvalue().decode("utf-8"))

72def _to_number(x):
73    try:
74        v = float(str(x).replace(",", "").strip())
75        return v if v >= 0 else None
76    except (ValueError, TypeError):
77        return None

79def compute_totals(rows):
80    totals = {}
81    total_all = 0.0
82    for r in rows:
83        if not (r.get("nama") or "").strip():
84            continue
85        cat = (r.get("kategori") or "").strip() or "Lainnya"
86        val = _to_number(r.get("harga"))
87        if val is None:
88            continue
89        totals[cat] = totals.get(cat, 0.0) + val
90        total_all += val
91    return totals, total_all

110def save_csv(rows):
111    out = io.StringIO()
112    writer = csv.DictWriter(out, fieldnames=["kategori", "nama", "harga"], delimiter=';')
113    writer.writeheader()

123def export_summary_json(totals, total_all, n_items):
124    data = {
125        "total_per_kategori": {k: round(v, 2) for k, v in totals.items()},
126        "total_semua": round(total_all, 2),
127        "jumlah_item": int(n_items)
128    }
129    return json.dumps(data, ensure_ascii=False, indent=2).encode("utf-8")

134def save_excel(rows, totals, total_all):
135    try:
136        import openpyxl
137    except ImportError:

139    
140    valid_rows = [r for r in rows if (r.get("nama") or "").strip()]

Penjelasan Mendalam 7 Bagian Source Code `app.py`

Bagian 1 (Baris 1 - 17) Page Configuration

Inisialisasi Halaman & Metadata Web Streamlit

  • • st.set_page_config(): Menentukan judul tab browser (page_title), ikon favicon (page_icon), serta perataan tata letak layout (layout="centered"). Perintah ini wajib dipanggil sebelum perintah antarmuka Streamlit lainnya.
  • • st.title() & st.caption(): Menampilkan elemen teks hierarki tingkat atas sebagai heading judul aplikasi beserta deskripsi sekunder.
Bagian 2 (Baris 20 - 46) Data Loader & State Persistence

Parsing String CSV Menjadi Objek & Session State

  • • io.StringIO(): Mengubah string teks biasa (SAMPLE_CSV) menjadi objek stream berkas di memori virtual komputer sehingga modul csv.DictReader dapat membacanya seolah-olah sedang membaca berkas fisik dari harddisk.
  • • csv.DictReader(..., delimiter=';'): Membaca baris pertama sebagai kunci dictionary dengan pemisah titik-koma.
  • • st.session_state: Karena Streamlit mengeksekusi ulang seluruh skrip dari atas ke bawah pada setiap event tombol atau perubahan input, inisialisasi ke dalam st.session_state.menu_data mencegah data editan ter-reset kembali ke nilai default.
Bagian 3 (Baris 48 - 67) Interactive Data Editor

Komponen Grid Interaktif (st.data_editor)

  • • column_config: Melakukan validasi tipe kolom. SelectboxColumn membatasi kategori hanya pada opsi ["Makanan", "Minuman", "Lainnya"]; TextColumn untuk input teks nama; NumberColumn untuk angka dengan batas minimum 0 dan kenaikan step 1000.
  • • num_rows="dynamic": Memungkinkan pengguna menambah atau menghapus baris sesuka hati pada tabel web.
Bagian 4 (Baris 69 - 105) Aggregation Logic

Validasi & Kalkulasi Akumulasi Ringkasan

  • • _to_number(): Membersihkan karakter koma dan spasi lalu mengonversinya secara aman ke tipe float. Mengembalikan None jika data tidak valid sehingga mencegah terjadinya error *ValueError*.
  • • totals[cat] = totals.get(cat, 0.0) + val: Pola akumulator dictionary standar Python untuk menjumlahkan total harga per kategori menu.
  • • st.columns(2) & st.metric(): Membagi layout menjadi 2 kolom: sisi kiri menampilkan tabel per kategori, sisi kanan menampilkan visual metrik total semua harga.
Bagian 5 (Baris 107 - 129) CSV & JSON Exporters

Konversi ke Byte Stream CSV & JSON

  • • save_csv(): Menggunakan csv.DictWriter dengan delimiter titik koma (;) untuk menyusun byte stream teks UTF-8 dari baris-baris menu yang telah diedit pengguna.
  • • export_summary_json(): Mengonversi dictionary hasil kalkulasi menjadi string JSON berindentasi menggunakan json.dumps() lalu di-encode ke format byte.
Bagian 6 (Baris 131 - 156) Excel Engine & Safety Handler

Solusi Ekspor Excel Multi-Sheet & Penanganan ImportError

  • • Blok try...except ImportError: Pengecekan penting untuk menangani error ModuleNotFoundError: No module named 'openpyxl'. Jika library belum terpasang, fungsi mengembalikan None secara anggun tanpa membuat aplikasi web *crash*.
  • • io.BytesIO(): Karena format dokumen Excel (.xlsx) adalah berkas terkompresi biner (ZIP OpenXML), maka penulisan di memori wajib menggunakan BytesIO() bukan StringIO().
  • • pd.ExcelWriter(..., engine="openpyxl"): Membuat berkas spreadsheet Excel profesional dengan dua lembar kerja terpisah: Sheet 'Daftar Menu' dan Sheet 'Ringkasan'.
Bagian 7 (Baris 158 - 197) Download Triggers

Komponen Download Button Streamlit

  • • Menampilkan 3 tombol download berdampingan menggunakan st.columns(3).
  • • Parameter mime disesuaikan dengan standar IANA: text/csv untuk CSV, application/json untuk JSON, dan application/vnd.openxmlformats-officedocument.spreadsheetml.sheet untuk Excel (.xlsx).
