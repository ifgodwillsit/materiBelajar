Bagian A • Alokasi Waktu: 60 Menit

A. Operasi Himpunan: `UNION`, `UNION ALL`, `MINUS`, dan `INTERSECT`

Operasi himpunan menggabungkan hasil dari dua atau lebih statemen SELECT. Syarat utamanya: setiap statemen SELECT yang digabungkan wajib memiliki jumlah kolom yang sama dengan tipe data yang serumpun, dan nama kolom hasil akhir akan mengikuti nama kolom dari SELECT yang pertama.

A.1. UNION vs UNION ALL Didukung MySQL

Menggabungkan baris dari dua himpunan ($A \cup B$). UNION otomatis menghapus duplikat (data kembar hanya muncul 1 kali), sedangkan UNION ALL mempertahankan semua duplikat.

SELECT * FROM prima
UNION [ALL]
SELECT * FROM genap;
A.2. MINUS (Selisih $A - B$) Emulasi LEFT JOIN

Memotong himpunan pertama dengan elemen yang ada di himpunan kedua ($A - B$). Keyword MINUS ada di Oracle (atau EXCEPT di MariaDB 10.3+), namun di MySQL standar dilakukan dengan LEFT JOIN ... WHERE tabel2.id IS NULL.

SELECT p.bilangan FROM prima p
LEFT JOIN genap g ON p.bilangan = g.bilangan
WHERE g.bilangan IS NULL;
A.3. INTERSECT (Irisan $A \cap B$) MariaDB / INNER JOIN

Mengambil hanya elemen yang ada di kedua himpunan sekaligus ($A \cap B$). Didukung oleh MariaDB dengan keyword INTERSECT, atau menggunakan INNER JOIN ... USING(...) maupun WHERE EXISTS (...).

SELECT DISTINCT * FROM prima
INNER JOIN genap USING(bilangan);

        Bagian B • Alokasi Waktu: 30 Menit
        
B. Konsep Subquery (Inner Query vs Outer Query) & Operator Pembanding

        

          Subquery adalah statemen SELECT yang disarangkan (*nested*) di dalam statemen utama (*outer query*) dan wajib ditulis di dalam tanda kurung (SELECT ...). Mesin basis data akan mengeksekusi Inner Query (Subquery) terlebih dahulu, lalu hasilnya disubstitusikan ke Outer Query.
        

      


      
      

        

          

             5 Aturan Penting Subquery (Halaman 4)
          

          
    
            
  1. Klausa ORDER BY tidak boleh digunakan di dalam subquery, namun boleh digunakan pada outer query (query induk).
    2. 
            
  2. Jika diletakkan di klausa SELECT, hasil subquery harus berupa satu nilai skalar/kolom.
    3. 
            
  3. Jika diletakkan di klausa FROM (Derived Table), hasil subquery berupa tabel dan wajib diberi alias.
    4. 
            
  4. Jika diletakkan di klausa WHERE, hasil subquery harus selaras melengkapi kondisi filter.
    5. 
            
  5. Dalam operasi pembandingan, subquery wajib diletakkan di sisi kanan operator pembanding.
    6. 
          

        


        

          

            Tabel 1. Operator Pembanding Subquery (Single-Row vs Multiple-Rows)
          

          

            

              
                

                  Operator
                  Bentuk Hasil Subquery
                  Cara Kerja & Logika Evaluasi
                

              
              
                

                  =, !=, <>, >, <, >=, <=
                  Single row (1 nilai skalar)
                  Membandingkan kolom dengan tepat 1 nilai tunggal hasil subquery. Jika subquery menghasilkan lebih dari 1 baris, MySQL akan mengeluarkan error Subquery returns more than 1 row.
                

                

                  IN, = ANY, SOME
                  Multiple rows / columns
                  Bernilai TRUE jika nilai cocok dengan salah satu elemen di dalam daftar hasil subquery.
• > ANY (72, 78) berarti lebih besar dari nilai terkecil (> 72).		
                

                

                  ALL (diawali =, >, <, dll.)
                  Multiple rows / columns
                  Membandingkan sebuah nilai terhadap SEMUA nilai hasil subquery.
• > ALL (72, 78) berarti wajib lebih besar dari nilai terbesar sekalipun (> 78).
• < ALL (2jt, 4jt, 5jt) berarti wajib lebih kecil dari nilai terkecil (< 2jt).		
                

                

                  EXISTS / NOT EXISTS
                  Boolean (Ada/Tidak ada baris)
                  Menguji apakah subquery mengembalikan minimal 1 baris data. EXISTS bernilai TRUE jika subquery tidak kosong.
