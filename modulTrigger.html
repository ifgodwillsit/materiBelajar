Otomatisasi Validasi & Audit Data dengan Database Trigger

Trigger adalah stored program khusus di dalam server basis data MySQL yang dieksekusi secara otomatis (di-invoke) ketika terjadi peristiwa manipulasi data DML (INSERT, UPDATE, atau DELETE) pada suatu tabel. Berbeda dengan Stored Procedure yang harus dipanggil secara eksplisit dengan CALL, trigger tidak dapat dilewati (*bypass*) oleh aplikasi luar selama transaksi melalui SQL MySQL.

Bagian 1 – 4 Materi Praktikum (Halaman 1 – 4)

1. Arsitektur Trigger, 6 Macam Trigger MySQL, & Aturan `OLD` vs `NEW`

Memahami bagaimana operasi DML dari aplikasi memicu eksekusi trigger di dalam tabel, kapan harus memilih waktu BEFORE vs AFTER, serta bagaimana mengakses data sebelum dan sesudah perubahan.

Ilustrasi Alur Kerja Trigger di Dalam Database Server (Gambar 1 Modul)

5 Keuntungan Trigger (Halaman 2 Modul)
  • Cara alternatif untuk mengecek integritas data secara terpusat di database.
  • Dapat memvalidasi dan mengoreksi input data sebelum masuk ke tabel (contoh: koreksi rak U-00 → U-01 pada Soal Unguided No. 6).
  • Menangkap error pada aturan bisnis (business logic).
  • Otomatis berjalan saat terjadi operasi DML tanpa perlu dipanggil manual dari aplikasi.
  • Sangat andal untuk mengaudit perubahan data (mencatat data lama OLD dan data baru NEW beserta waktu NOW() ke tabel log).
3 Kelemahan & Batasan Trigger (Halaman 2 Modul)
  • Hanya validasi tambahan: Validasi utama antarmuka pengguna tetap wajib dibuat di level aplikasi (PHP / JavaScript / Python).
  • Tidak terlihat (Invisible) dari sisi aplikasi client: Programmer aplikasi sering kesulitan melacak perubahan nilai atau proses di balik layar jika dokumentasi trigger tidak jelas.
  • Menambah beban (Overhead) server database: Karena dieksekusi untuk setiap baris (FOR EACH ROW), operasi DML massal ribuan baris akan memicu ribuan eksekusi trigger sekaligus.

Matriks 6 Macam Trigger MySQL & Aturan Penggunaan Pseudo-Record `OLD` vs `NEW`

SET NEW.kolom = ... HANYA BISA DI BEFORE!
No Jenis Trigger Contoh Penamaan Standar Modul Akses `OLD.kolom` Akses `NEW.kolom` Kegunaan Utama dalam Praktikum
1 BEFORE INSERT before_buku_insert ❌ Tidak Ada ✅ Bisa Baca & UBAH (SET NEW.col = ...) Memvalidasi & memodifikasi nilai input sebelum disimpan ke tabel (Contoh: Unguided No. 6 koreksi rak buku 00 → 01 dan >50 → 50).
2 AFTER INSERT after_buku_insert ❌ Tidak Ada ✅ Hanya Baca (Read-Only) Mencatat log penambahan data baru ke tabel audit/log setelah data resmi tersimpan (Contoh: Unguided No. 2 log_pindah_buku).
3 BEFORE UPDATE before_employee_update ✅ Hanya Baca (Nilai Lama) ✅ Bisa Baca & UBAH (SET NEW.col = ...) Menyimpan arsip data lama sebelum tertimpa (Contoh: Guided `employeesaudit`) atau memvalidasi nilai baru sebelum di-update (Hidden Question A).
4 AFTER UPDATE after_buku_update ✅ Hanya Baca (Nilai Lama) ✅ Hanya Baca (Nilai Baru) Mencatat riwayat perpindahan dari OLD.posisi_buku ke NEW.posisi_buku setelah update berhasil (Contoh: Unguided No. 3).
5 BEFORE DELETE before_buku_delete ✅ Hanya Baca (Data yang akan dihapus) ❌ Tidak Ada Memeriksa syarat otorisasi atau membatalkan penghapusan data penting dengan SIGNAL SQLSTATE '45000' (Hidden Question C).
6 AFTER DELETE after_buku_delete ✅ Hanya Baca (Data yang baru dihapus) ❌ Tidak Ada Mencatat jejak data yang telah dihapus ke tabel arsip/log (Contoh: Hidden Question B).

             Bedah Sintaks Penting (Halaman 4–5)
          

          

            

              
DELIMITER $$ ... END$$ DELIMITER ;

              
Secara default MySQL memakai titik-koma (;) sebagai penanda akhir perintah. Karena di dalam blok BEGIN ... END terdapat perintah SQL yang diakhiri ;, kita mengubah pembatas sementara menjadi $$ agar MySQL tidak mengeksekusi trigger secara prematur di tengah jalan.

            

            

              
BEFORE UPDATE ON employees FOR EACH ROW

              
Menentukan bahwa trigger aktif pada tabel employees sesaat sebelum operasi UPDATE diterapkan, dan dijalankan satu kali untuk setiap baris yang terkena dampak (FOR EACH ROW).

            

            

              
INSERT INTO employeesaudit SET action = 'update', ...

              
Di MySQL, perintah INSERT INTO nama_tabel SET col1 = val1, col2 = val2 adalah bentuk alternatif yang sah dari INSERT INTO ... VALUES (...) yang memudahkan pembacaan karena nama kolom ditulis berdampingan langsung dengan nilainya.

            

            

              
OLD.employeeNumber, OLD.firstName, OLD.lastName

              
Mengambil nilai kolom sebelum diubah oleh perintah UPDATE (yakni firstName = 'Agatha'), lalu menyimpannya ke tabel employeesaudit bersama waktu saat ini NOW().
