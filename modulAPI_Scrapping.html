1. Konsep HTTP Request, Response, & Aplikasi `strukdat07_http.py`

HTTP (HyperText Transfer Protocol) adalah aturan komunikasi antara Client (browser / skrip Python) yang mengirim Request dan Server yang membalas dengan Response.

Komponen HTTP Request & Response

📤 4 Komponen HTTP Request (Client → Server):
  • • 1. URL: Alamat tujuan (misal https://www.example.com).
  • • 2. Method: GET (ambil data), POST (kirim data), PUT (perbarui), DELETE (hapus).
  • • 3. Headers (Opsional): Metadata seperti User-Agent: Mozilla/5.0 atau Authorization: Bearer <token>.
  • • 4. Body (Opsional): Payload data yang dikirim saat POST / PUT.
📥 3 Komponen HTTP Response (Server → Client):
  • • 1. Status Code (3 Digit): 200 OK (Sukses), 404 Not Found (Tidak ditemukan), 500 Internal Server Error.
  • • 2. Headers: Informasi tipe konten (misal Content-Type: text/html atau application/json).
  • • 3. Body: Isi balasan yang diakses via response.text (teks/HTML) atau response.content (bytes biner gambar/PDF).
Properti / ModeTipe DataPeruntukan File
response.text + open("w")str (UTF-8)HTML, TXT, CSV, JSON
response.content + open("wb")bytes (Binary)Gambar (.jpg/.png), PDF, Audio
